# 界面与实现规格

## 产品定位

Remote Microphone 是独立的 iPhone 发送端与 Mac 接收端。远程桌面应用负责画面与控制；本项目传送音频并输出到 BlackHole。用户先主动开始手机会话，再切换到 UU。停止按钮结束该会话。

名称统一使用 **Remote Microphone**。手机与 Mac 共用图标。没有独立悬浮麦克风按钮，也没有隐藏的悬浮窗口入口。

## 视觉约定

先更新 `mock/index.html`，再据此实现原生界面。

| 项目 | 约定 |

| 背景 | 白色；控件浅灰 `#F6F7FA` |
| 主色 | `#3388FF` → `#4C94FF` 蓝色渐变 |
| 文字 | 主文字 `#20232A`，次要文字 `#7D8490` |

| 标题 | 20 pt；完整产品名称保持一行 |
| 次级按钮 | 36 pt 图标按钮 |

| Mac 卡片 | 宽 350 pt，底部主按钮高 46 pt |

手机主界面包含连接状态、目标 Mac、波形、主操作和底部加密连接标志；在小屏幕上可滚动。手机应用使用纵向布局，不限制 UU 自己的横竖屏。Mac 主界面包含手机名称、状态、波形、设备选择和接收按钮。技术参数和长篇解释放在文档，不堆进产品主界面。

## 波形

- 只绘制测量值，不在静音时播放假动画。
- 将定时器身份保存在 SwiftUI State 中，避免实时电平更新导致订阅反复重建。
- 30 Hz 采样显示；24 个柱子覆盖约 0.8 秒历史。
- RMS 转换到 −60…−18 dBFS 的显示区间；立即起跳，按每帧 0.76 系数回落。
- 上述变化只影响显示，不增加 PCM 或网络音频增益。
- 停止、开始和视图重新出现时清空旧历史。
- 遵循“减少动态效果”，关闭插值动画但继续显示测量值。
- [波形夹具](../e2e/Waveform.swift) 使用生产共享组件与明确模拟电平；不能代替真实收音验收。

## 配对与协议边界

首次启动不预填开发者地址。用户在停止接收时填写自己的 Mac Tailscale 地址；保存前不显示有效二维码，不允许复制空地址配对链接。

协议 v4 使用 DTLS 1.2 PSK / AES-GCM，AAC-LC 单声道 48 kHz、目标 32 kbps。两端以 HELLO 的单调时钟增量计算额外排队时间。接收端 AUHAL 输出缓冲有上限；认证完成后的新连接可替换旧连接，同一时刻仅输出一路音频。

正常应用不保存录音，不自动切换系统默认音频设备。网络丢失后，用户已启动的手机会话保留并重试；声音不排队补播。电话、路由切换与媒体服务重置会明确结束录音，要求用户重新开始。

## 原生验收

检查空闲、开始、传送、停止、重新连接和配对状态；检查名称、颜色、24 柱波形、设备选择和无悬浮层。截图明确标注 mock / 模拟夹具 / 真机来源。

公开截图仅保存经过检查的通用界面，不上传配对二维码、个人设备名称、IP、账户信息或真实语音。原始验收产物放在被忽略的 `artifacts/`，可公开的截图放在 `docs/images/`。

## 配对地址可见性

手机和 iPad 主界面在目标 Mac 名称下显示已保存的 host:port；IPv6 地址使用方括号。配对页显示“当前配对”的 Mac 名称和地址，扫码成功后保留该页供核对，点击“完成”返回。地址从已保存配对读取，不显示密钥，也不把已配对当作已连通。
