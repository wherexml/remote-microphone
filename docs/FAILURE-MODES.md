# 故障与验收边界

在修改行为前列明失败场景，优先通过端到端检查验证。单个工具返回成功、波形跳动或网络连接建立，都不等于整个听写链路成功。

## 配对与连接

- 缺失 / 错误密钥：DTLS 握手失败，不能降级为明文。
- 空地址：不生成可分享的配对 URL，用户仍可输入地址并保存。
- 多个连接：未认证连接不占用唯一音频通道；新连接经密钥与 HELLO 验证后可以替换旧会话，不能混音。
- 挂起握手：最多四个待认证连接，不让单个旧连接长期阻塞合法重连。
- 数据报重复 / 乱序：序列号去重；只重试幂等控制消息，不重传旧音频。
- HELLO / 确认丢失：允许控制重试，不能重复初始化音频会话。
- 协议版本、格式、长度、cookie 不匹配：明确关闭，不把任意字节当音频。
- Tailscale 关闭、地址不可达或手机无网络：保持明确连接状态；不能把未接通显示为传送中。

## 音频与生命周期

- 麦克风权限拒绝：明确显示错误，不能声称录音。
- 切换到 UU：已明确开始的会话在后台继续采集；锁屏与低电量另行验收。
- 电话 / 蓝牙切换 / 媒体服务重置：释放资源、明确中断，不能偷偷重新启动用户已停止的录音。
- 网络丢失：丢弃待发送音频，保留该用户会话并按退避策略重连。
- 用户停止：取消重试；旧连接回调不能重开或破坏新会话。
- 接收进程暂停 / 退出 / 恢复：静音旧音频，重建时使用新的 HELLO 时钟锚点。
- 驱动缺失：提示设备不可用，不能自动把语音送到扬声器。
- 采样率不一致：显式重采样，不能出现音高和速度变化。
- 输入帧数：使用 `frameLength` 而不是 `frameCapacity`，不得把未使用缓冲容量当有效声音。
- 实际格式：验证浮点、声道和采样率；选择设备 ID 成功不代表采集格式已同步。
- 反馈：先停止，再关闭远程电脑声音；不能只凭语音处理开关宣称已消除回音。

## 有界缓冲

- 原始 PCM 在差网络下可能积压数秒；使用生产 AAC 编码路径测试，不能只测 PCM 数据往返。
- 对过期数据静音，不恢复播放断线期间的旧内容。
- 接收侧环形缓冲上限 160 ms；实际可能丢弃数据，不能描述为无损网络传输。
- 单调时钟增量避免两台设备墙钟偏差误丢正常音频。

## 波形回归

- 电平以 20–100 ms 更新时，历史波形仍能推进，不能反复重建定时器导致停滞。
- 轻声可见，静音归零，没有假动画。
- 短音节及时出现、自然回落；停止 / 重新开始不保留旧峰值。
- 显示灵敏度与真实音频增益分离，不能通过随意加大声音来修复视觉效果。

## 验收证据

| 层次 | 方式 | 不能据此证明 |
| --- | --- | --- |
| 协议 | `verify-transport.sh`，真实本机 DTLS 套接字与错误密钥 | 真机权限、蜂窝连通 |
| 音频 | `verify-loopback.sh`，生产 AAC → Mac → BlackHole → 独立输入 | 手机实际收音、语言识别准确率 |
| 会话恢复 | `verify-recovery.sh`，未认证候选 / 新会话替换 / 显式停止 | 所有运营商和长期后台稳定性 |
| 波形 | 原生共享组件夹具，模拟轻声与静音截图 | 真实声音已进入目标应用 |
| 真机 | 真实 iPhone、关闭 Wi-Fi、UU 前台、独立 BlackHole 捕获 | 所有设备、网络和识别模型均可靠 |
| 听写 | 核对实际目标应用、所选麦克风、实际识别服务和输出文字 | 仅靠离线模型回放不能替代此项 |

测试录音应有采集格式、回调数、有效数据块、WAV 和校验哈希。没有输入回调必须报错；“文件创建成功”不是录音成功。

## 提交隐私边界

正常应用不录音落盘；独立验收工具会录音。配对密钥只存于应用私有存储或本机临时文件，不进入日志、截图、Issue 或 Git。原始测试录音、转写、账户资料、签名配置与诊断留在被忽略的本地目录，只提交经过检查的通用截图和汇总。

## 扫码配对验收（2026-10-26，2026-10-29 修订）

- 首次输入裸 IP：说明缺少配对密钥，保留输入和面板，不改已有配对。
- 无效二维码：保持扫描，显示错误；有效码仅处理一次，保存成功才关闭配对页。
- 相机拒绝 / 无相机：明确错误，可返回粘贴链接；取消和退到后台释放相机。
- 录音期间禁用重新配对；iPad 横竖屏预览随容器布局，无强制机型限制。
- 手机端未在本安装内确认过的配对不显示为已连接 Mac：全新/无钥匙串显示「未配对 · 扫码连接 Mac」；删 App 后钥匙串残留显示「上次配对：名称」并可继续或忘记；仅扫码/粘贴成功（或点继续使用）后才显示二维码里的 Mac 名称并允许开始传声。
- 配对链接使用 `remotemic://pair?p=` 查询参数承载密钥；系统相机打开自定义 URL 时可能丢掉 `#fragment`，旧版 fragment 链接仍可解析，但不能把「只扫到 IP / 打开后 fragment 丢失」当成已配对。
- 旧 remotemic 链接继续可用；不能为支持 IP 输入绕过 DTLS 密钥。
