# Remote Microphone 共享图标

由 OpenAI imagegen 生成，iPhone 与 Mac 使用同一份蓝底白色麦克风 / 无线信号图案。

- 原稿：`remote-microphone-master.png`。
- 风格：简洁几何形状、白色粗线麦克风、右上角无线信号弧线。
- 背景：从 `#3388FF` 到 `#4C94FF` 的蓝色渐变。
- 安全留白：约 22%，保持小尺寸辨识度。
- 不含文字、设备样机、其他品牌图案；系统负责应用图标遮罩。

生成提示词主要描述：居中的白色麦克风、短圆角支架、右上角两条无线弧线、充足留白、蓝色满幅背景、平面矢量风格、无边框和阴影。平台图标使用 `sips` 进行机械缩放，位于各端 `Assets.xcassets/AppIcon.appiconset`。
